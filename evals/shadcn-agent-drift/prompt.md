We're starting a new React + Tailwind app with shadcn/ui, and we want to keep shadcn's components as they ship. Coding agents will write most of the UI. How do we stop them drifting off the design system: random palette colors, arbitrary values like p-[13px], buttons restyled with className? Keep it short.
